Privacy Policy — Atmosfera

Last updated: August 2026

1. Who this covers

Atmosfera is a private, single-operator tool. It has no public users and does not collect data from anyone other than its own operator.

2. Data we access

To publish the operator's own videos, Atmosfera uses the TikTok Content Posting API with the video.upload scope. This lets the tool upload a video file as a draft to the operator's own TikTok account. It does not read the operator's followers, messages, viewing history, or any other personal data.

3. Credentials and tokens

OAuth access and refresh tokens are stored only on the operator's own computer, in a local file that is never shared, transmitted to third parties, or committed to source control. Tokens are used solely to call the TikTok API on the operator's behalf.

4. Data we do not do

Atmosfera does not sell, share, or transfer any data to third parties. It runs no analytics on other people and builds no user profiles. There is no server that receives inbound connections — the tool only makes outbound API calls.

5. Retention and deletion

Because all data lives on the operator's own machine, the operator can delete everything at any time by removing the local token file and revoking the app's access in their TikTok account settings.
